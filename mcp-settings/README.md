# MCP 설정 문서

이 폴더는 프로젝트에서 사용하는 MCP 서버의 설정과 인증, 연결 확인 방법을 서비스별로 정리한다. 새 MCP 서버를 추가할 때는 이 안내와 [문서 템플릿](TEMPLATE.md)을 사용한다.

## 문서 목록

- [Notion](notion.md) — Notion의 원격 MCP, Codex/Orca 프로젝트 설정, OAuth 확인 절차
- [새 MCP 문서 템플릿](TEMPLATE.md) — 다음 서버를 기록할 때 복사해서 사용

## 공통 설정 원칙

1. 설정을 바꾸기 전에 현재 에이전트 세션에서 서버 도구가 노출되는지와 기존 설정 파일을 확인한다.
2. MCP 설정 형식과 적용 범위는 클라이언트마다 다르다. Orca 프로젝트 설정 화면에서 파일이 보인다는 사실만으로 현재 에이전트가 그 파일을 읽는다고 단정하지 않는다.
3. 기존 설정은 보존하면서 서버 항목만 병합한다. 토큰과 비밀값은 저장소 문서나 프로젝트 설정 파일에 넣지 않는다.
4. 설정 등록, OAuth 인증, 세션에서 도구 노출 확인은 서로 다른 단계로 기록한다. 한 앱의 인증을 다른 클라이언트의 인증으로 간주하지 않는다.
5. 인증이 필요한 서버는 사용자가 OAuth 동의를 완료하도록 안내한다. 연결 후 새 에이전트 세션에서 실제 도구가 보이는지 확인한다.

## 문서 추가 방법

새 서버마다 `<서버명>.md` 파일을 만들고, 템플릿에 공식 엔드포인트와 클라이언트별 설정 형식, 인증 절차, 확인 명령, 공식 참고 링크를 기록한다. 확인되지 않은 URL이나 설정 키는 추측해서 적지 않는다.
